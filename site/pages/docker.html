title: Clean up Docker and OrbStack disk space on Mac nav: Docker and OrbStack icon: box description: Free disk space used by Docker Desktop, OrbStack and Colima: remove build cache, unused images, stopped containers and volumes with Docker's own commands. lead: Build cache, old images and stopped containers add up fast. Reclaim lists them with the sizes Docker reports and removes them the way Docker intends. ---

What you need

The docker command and a running engine: OrbStack, Docker Desktop, Colima or another. {{app}} finds the command in the usual places, even when it is opened from Finder. Open Containers in the sidebar. If the engine is not running, start it and click Refresh.

What is listed

ItemWhat it isRemoved withLevel
Build cacheLayers kept to speed up builds, not used by any image now. One item.docker builder prune --allSafe
Dangling imageAn untagged image left behind when a newer build took its tag.docker image rmSafe
Unused imageA tagged image no container uses. Pulled or built again when needed.docker image rmRebuild
Stopped containerA container that is not running. Changes made inside it are lost.docker container rmRebuild
Unused volumeA volume no container uses. These often hold databases.docker volume rmPersonal

Images, containers and volumes that are in use are never listed. Select a row to read what it is and what happens after removing it.

How removal works

{{icon:shield-check}}

Ticked items are removed with Docker's own commands, never forced, so Docker itself refuses anything a container is using. {{app}} never touches the engine's disk image directly.

Docker items share the Delete bar and the history with everything else. If Docker refuses an item, the summary shows Docker's reason and the item stays in the list.

About the sizes

Sizes come from docker system df. For an image, {{app}} shows the space only that image uses, which is what removing it frees; layers shared with other images stay. Totals can differ slightly from Docker's own summary because Docker rounds each size it reports.
