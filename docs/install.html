Install Reclaim

Three steps: download, open it once through System Settings, and give it Full Disk Access so it can see the whole disk.

Requirements

  • macOS 14 Sonoma or later.
  • Apple silicon or Intel. The app is a universal binary, but it is tested on Apple silicon only.

Download

  1. Open the latest release and download Reclaim.zip, plus Reclaim.zip.sha256 if you want to check it.
  2. Optional: check the download is intact. In Terminal, in the folder you downloaded to: 
    shasum -a 256 -c Reclaim.zip.sha256
    It should print Reclaim.zip: OK.
  3. Double-click Reclaim.zip and drag Reclaim into your Applications folder.

Open it the first time

Reclaim is not notarized by Apple, because that needs a paid developer membership. macOS therefore blocks it the first time. You only do this once per version.

  1. Double-click Reclaim in Applications. macOS says it cannot verify the app. Click Done.
  2. Open System Settings › Privacy & Security and scroll down to the Security section.
  3. Next to the message about Reclaim, click Open Anyway, then confirm with your password or Touch ID.

The source is public, so you can also build it yourself instead of trusting a download.

Give it Full Disk Access

Without it, macOS hides parts of your Library folder and other apps' data, so the scan misses them. The Overview tells you how many folders could not be read.

  1. Open System Settings › Privacy & Security › Full Disk Access.
  2. Click +, choose Reclaim in Applications, and make sure its switch is on.
  3. Quit and reopen Reclaim, then scan again.

No app can grant this to itself, and Reclaim never asks for it again once it is on.

Updating

Download the new release and replace the old app in Applications. Because each build is signed separately, macOS may ask you to repeat Open Anyway, and you may need to switch Full Disk Access off and on again.

Uninstalling

  1. Quit Reclaim and move it from Applications to the Trash.
  2. To remove its settings and deletion history too, delete these: 
    ~/Library/Preferences/io.github.kstmostofa.reclaim.plist
~/Library/Application Support/Reclaim
  3. Remove it from Full Disk Access in System Settings.

Building from source

You need Xcode and XcodeGen (brew install xcodegen).

git clone https://github.com/kstmostofa/reclaim.git
cd reclaim
xcodegen generate
open Reclaim.xcodeproj

Run the engine's tests with swift test in Packages/ReclaimCore. They only ever create and delete files in temporary folders.
