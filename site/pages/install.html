Requirements

  • macOS 14 Sonoma or later.
  • Apple silicon or Intel. The app is a universal binary. It is tested on Apple silicon.

Download

  1. Get the app. Open the latest release and download Reclaim.zip, plus Reclaim.zip.sha256 if you want to check it.
  2. Optional: check the download. In Terminal, in the folder you downloaded to, run the command below. It should print Reclaim.zip: OK. 
    shasum -a 256 -c Reclaim.zip.sha256
  3. Move it to Applications. Double-click Reclaim.zip and drag Reclaim into your Applications folder.

Open it the first time

{{app}} is not notarized by Apple, because notarization needs a paid developer membership, so macOS blocks it the first time. You do this once per version.

  1. Try to open it. Double-click Reclaim in Applications. macOS says it cannot verify the app. Click Done.
  2. Open Privacy & Security. Go to System Settings › Privacy & Security and scroll to the Security section.
  3. Allow it. Next to the message about Reclaim, click Open Anyway and confirm with your password or Touch ID.
{{icon:info}}

The source is public, so you can also build it yourself instead of trusting a download.

Give it Full Disk Access

Without it, macOS asks for permission the first time any app opens Desktop, Documents, Downloads, iCloud Drive or another app's data, and the app has to wait for your answer. To keep scans from stalling, {{app}} skips those folders until it has Full Disk Access, and the Overview says so with a button to the right settings page.

  1. Open the setting. Go to System Settings › Privacy & Security › Full Disk Access.
  2. Add Reclaim. Click +, choose Reclaim in Applications, and make sure its switch is on.
  3. Scan again. Quit and reopen Reclaim, then scan.

No app can grant this to itself, and {{app}} never asks again once it is on.

{{icon:info}}

Your Music, TV and Photos libraries are always skipped, even with Full Disk Access, because macOS protects them with permissions of their own. {{app}} never suggests anything inside them.

Updating

Download the new release and replace the old app in Applications. Because each build is signed separately, macOS may ask you to repeat Open Anyway, you may need to switch Full Disk Access off and on again, and the helper, if you use it, asks to be paired again.

Uninstalling

  1. Remove the helper, if you installed it: open System in the sidebar and click Remove Helper….
  2. Remove the app. Quit Reclaim and move it from Applications to the Trash.
  3. Optional: remove its settings and history. 
    rm ~/Library/Preferences/io.github.kstmostofa.reclaim.plist
rm -r ~/Library/Application\ Support/Reclaim
  4. Tidy up permissions. Remove it from Full Disk Access and, if you turned it on, from Login Items in System Settings.

Building from source

You need Xcode and XcodeGen.

brew install xcodegen
git clone {{repo}}.git
cd reclaim
xcodegen generate
open Reclaim.xcodeproj

The engine's tests run with swift test in Packages/ReclaimCore. They only ever create and delete files in temporary folders.
