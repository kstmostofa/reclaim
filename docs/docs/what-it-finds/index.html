What it finds

Every folder Reclaim suggests deleting on a Mac, including .next, node_modules, vendor, DerivedData, Gradle, npm and pip caches, Docker and system junk.

Every suggestion comes from one of these rules. A rule looks only at a folder's name, where it is and the files beside it; once a folder matches, nothing inside it is listed again. ~ means your home folder.

Dependencies

Packages your project installed. Run the install command again before using the project.

WhatMatched whenTo get it backLevel
Node packagesnode_modules beside a package.jsonnpm install, pnpm install or yarnRebuild
Composer packagesvendor beside a composer.jsoncomposer installRebuild
CocoaPodsPods beside a Podfilepod installRebuild
Python virtual environmentvenv, .venv or env containing pyvenv.cfgpython -m venv, then reinstall requirementsRebuild
Packages that tools installed for themselves are skipped: anything in a hidden folder in your home (such as ~/.vscode/extensions or ~/.composer), in ~/Library, or in system and Homebrew locations. Deleting those would break the tool, and there is no project to reinstall into.

App leftovers

Folders in ~/Library/Containers and ~/Library/Application Support named after an app's identifier (such as com.docker.docker) when no installed app has that identifier. Apple's own folders are never included, and an extension's folder counts as its app's. Personal

Large files

Files of 500 MB or more (adjustable) that no rule above covers, outside apps and photo libraries. Personal

Docker

From Docker's own disk-usage report, when an engine is running. See Docker and OrbStack.

System junk

Most of these belong to root, so deleting them needs the helper. Items macOS protects are skipped even then.

WhatLocationLevel
System cacheeach folder in /Library/CachesSafe
System logseach item in /Library/Logs and /private/var/logSafe

Never suggested or deleted

  • Anything inside an app, framework, photo or music library, or other bundle.
  • Folders you list under Never scan these folders.
  • Your Music, TV and Photos libraries, which macOS protects with permissions of their own.
  • Protected folders, which cannot be deleted as a whole from anywhere in the app. See the FAQ.
